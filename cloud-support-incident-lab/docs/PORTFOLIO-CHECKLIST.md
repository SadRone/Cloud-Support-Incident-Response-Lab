# Portfolio Completion Checklist

Do not put the project on your CV until the repository contains evidence.

- [ ] Healthy architecture screenshot
- [ ] Grafana dashboard with generated traffic
- [ ] Incident 01 report: app container stopped
- [ ] Incident 02 report: Redis dependency stopped
- [ ] Incident 03 report: incorrect Nginx upstream port
- [ ] Incident 04 report: high latency
- [ ] Before and after screenshots for every incident
- [ ] Commands and relevant log excerpts
- [ ] Root cause and validation for every incident
- [ ] Architecture diagram
- [ ] English README proofread
- [ ] Public GitHub repository without secrets
- [ ] Two-minute screen recording or GIF, optional
